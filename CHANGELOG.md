# Changelog

## 1.0.0 - 2026-08-30

- Initial public release.
- Renamed ambiguous FAST/SLOW-style application naming to physical CAN1/CAN2
  controller names.
- Added bounds-safe indexing for the 37-frame emulator table.
- Restored the missing CAN1 filter activation for IDs `0x0F8` and `0x74E`.
- Added hardware, build, VIN and button documentation.
